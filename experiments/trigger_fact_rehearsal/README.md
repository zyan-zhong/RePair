# Trigger-window and factual-binding rehearsal

These are exact, registered experiment utilities, archived after the paper
release. They do not replace the existing trainer, native decoder, campaign
owner, or scientific acceptance rules. No model weights or case payloads are
included. `PROVENANCE.json` records source hashes and the deployment ZIP hash.

The supervised-learning hypothesis is that redundant Local research visits can
focus more on the selected call window and its supporting facts **after the
complete original teacher target has received positive-learning-rate coverage**.
Full input rows and teacher targets stay unchanged. ACTION/STRATEGY and nonlocal
samples retain their original masks. The within-RESEARCH token loss allocation
changes; this is not a claim that all loss contributions stay identical.

## Files and interfaces

| File | Purpose |
|---|---|
| `fact_rehearsal.py` | Transform redundant Local sample masks and prove complete positive-LR research coverage |
| `fact_practice.py` | Bind character/token spans of existing `call_window` and `facts_at_trigger` values |
| `target_binding.py` | Resolve current conditional teacher targets before historical shared provenance; require an existing approval/proof for a lossless execution view |
| `prepare_rehearsal.py` | Allocated-job tokenizer proof and materialization using the existing caller's checked references and immutable writer |
| `supervision_coverage.py` | Find a complete prefix of the existing sample schedule; this utility alone does not prove positive-LR exposure |

The caller supplies the SHA-checked dataset authority, exact registered refs,
tokenizer and immutable output functions. `target_for_row()` requires current
row admission, and its `checked` callback must actually verify reference hashes;
historical rendering flags are not current execution admission. Peer helpers
are loaded by the entry file path to prevent an older native module from
shadowing the intended implementation.

No directory discovery, latest/mtime choice, new diagnosis, inferred fact, or
manual parser selection is performed by these utilities. They are not a
standalone launcher: missing private inputs must not be replaced with invented
data or an unregistered model. Keep model/tokenizer loading in the registered
allocated GPU job. Offline unit tests do not load either.

## Offline verification

From the repository root:

```bash
python -m unittest discover -s experiments/trigger_fact_rehearsal -p 'test_*.py'
python tools/verify_release.py
python tools/verify_registered_sources.py
```

The 22 unit tests cover complete-before-focus scheduling, zero-LR and fragmented
coverage, unchanged policy/nonlocal samples, no teacher-token substitution,
module shadowing, current-target precedence, approved-view identity and
supervision coverage. They demonstrate engineering boundaries, not scientific
learning or complete role competence. The deployment package has 16 additional
inherited tests that are not counted as part of this standalone test directory.

## Default observation entry correction

`observer_entry.py` binds the existing default and shadow authority slots to the
same SHA-registered current task. The old owner only replaced the shadow slot,
so the default command could still display a completed B control. Two offline
regressions cover both slots, idempotence, preserved renderer flags and rejection
of unknown entry layouts. The server change preserves the prior wrapper and an
immutable adoption receipt; no active scientific package, training data, role
prompt, renderer or color scheme was changed. Future entry construction must
reuse the new adoption receipt rather than the stale central-script SHA.

The revised design requires SFT task success to exceed the verified comparable
framework best before any RL pilot. Role/decision process credit, smaller trial
budgets and the reason for each suggestion remain under discussion. No RL
reward or loss is approved by this archive.
