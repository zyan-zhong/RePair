# Implementation review and known boundaries

## Reuse, not replacement

The current fixed repository supplies the evaluator, five-file attempt loader,
SELECT I1 identity audit, condition schedule validation, numeric paired aggregator,
promotion-decision contract, next-round creation and stage receipt contract.
This delivery adds a completion-gated consumer and isolated source publisher only.
The legacy pilot result wrapper is not reused. Numeric outputs are projected by
an explicit field allowlist into a clean diagnostic aggregate.

## Scientific authority

The frozen protocol and candidate both prohibit promotion for this diagnostic arm.
A positive SELECT delta must not be converted to candidate promotion. The native
ROLLBACK disposition retains the parent, while preserving the actual observed delta.
It is not a newly invented statistical NO-GO threshold.

No confidence interval, statistical significance test, equivalence threshold,
selective retry rule or training change is introduced after partial outcomes.
The entire exact task-seed universe is audited before aggregation.

## Publication

All work happens in an independent local clone of the exact active Git history.
Tests and source-map generation do not modify the active checkout. Only explicitly
listed execution source files and audited aggregate/decision artifacts are staged.
An atomic push updates the integration branch and main only when main is an
ancestor. Real temporary bare Git repositories test isolation, atomic publication
and rejection of divergent histories. The assistant has not pushed the user's
repository in this session.

The complete code map is generated on the server from its authoritative Git tree.
The provided preview is labeled as source-export-based, with unavailable files
identified rather than substituted. It is not a fully resolved dynamic call graph.

## Operational behavior

Active jobs are not duplicated or cancelled. The driver does not treat COMPLETED
alone as a full experiment closure. Failed jobs stop. A successful graceful partial
can resume the existing 4-GPU package once at most, within its original per-job
resource request. An uncertain submission stops instead of retrying.
No CPU or memory requests are added to any GPU job by this delivery.

The script preserves execution logs and partially written closeout outputs.
No policy/model training, provider request, or new ALFWorld episode is implemented
in the audit adapter. The only possible scientific invocation is the explicitly
bounded reuse of the existing resumable SELECT launcher.

## Remaining evidence requirements

The filtered handoff omitted the E1 episode schema and several source files.
Consequently, no full fixed-repository regression is claimed locally. The server
runs the full native tests plus all five native integration tests before proceeding.
The missing schema is not regenerated or mocked. Current SELECT source execution
already demonstrates that the server has dependencies absent from the filtered copy.

This delivery leaves the original archive-provenance flag false. It does not claim
a Strong-primary round has run or a local shadow model exists. Takeover metrics,
new resource budget and actor/model bindings must come through existing governed
artifacts. No routine human scientific decision or human fallback is inserted.
