# Human Pilot Stage 0 Completion — Design V1

Stage 0 closes the contaminated Human pilot as engineering evidence only. It reuses the frozen SELECT evaluator, twin policy bindings, task-access governance, existing parent/candidate adapters, and canonical episode evaluator. It does not create a second ALFWorld evaluator, does not commit or push repository changes, does not promote the candidate, and does not authorize paper efficacy claims.

The live comparison is 17 `SELECT_SUMMARY_ONLY` tasks × five frozen evaluation seeds for each of the parent and candidate policies: 85 matched cells per policy, 170 total condition cells. The primary statistical unit remains the unique task; seeds are within-task stochastic replicates.
