# RePair

RePair studies how corrections proposed from failed agent trajectories can become useful training evidence and, ultimately, capability retained by a policy.

The research workflow proposes repairs, tests them with paired continuations from the same environment state, trains on verified evidence, and evaluates the resulting policy with external repair assistance and failure memory disabled.

## Release status

This repository is the public entry point for an upcoming code release. It currently contains this release notice only; the implementation, experiment scripts, configurations, and reproduction instructions are being prepared. The full training workflow cannot yet be run from this repository.

The release will distinguish intervention success, intermediate progress, and unassisted policy performance. It will document completed experiments and remaining evidence gaps without presenting planned experiments as results.

Operational histories, credentials, private server locations, and raw provider logs will not be included in the public release. Third-party code and assets will retain their original license and attribution requirements.
