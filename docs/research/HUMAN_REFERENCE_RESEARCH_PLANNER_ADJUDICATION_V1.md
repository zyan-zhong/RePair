# Human Reference Research Planner Adjudication V1

## Purpose

This stage converts the recovered evidence-rich 30-pair Analyzer archive into
the first fully documented Human Research Planner PRE demonstration.

It is not an effect-labeling stage. It records:

```text
evidence and counterevidence
→ expected research value and Harm risk
→ A2/A3 pair adjudication
→ selected / rejected / deferred directions
→ one principal change
→ one 12-state verification portfolio
→ frozen endpoint and stop rule
```

The independent environment verifier remains the only authority for
Benefit/Harm/Neutral/Uncertain.

## Why the selected portfolio is 11 A2 + 1 A3

There is no A2/A3 quota.

For 27 of 30 states, A2 and A3 project the same environment intervention. The
Human reference therefore uses A2 as the minimal current-evidence lineage
unless the A3 history-bounded analysis changes the audit interpretation.

One state uses A3 because:

```text
A2 Formal X = DOWNGRADE_SCOPE
A3 Formal X = ACCEPT
environment action = identical
```

This is an evidence/scope decision, not a causal claim that Memory improves the
repair. A3-vs-A2 Memory value remains an Analyzer ablation to be evaluated by
downstream verified repair yield.

## Portfolio design

The selected 12 states satisfy:

```text
six task families
two states per family
twelve unique Analyzer groups
twelve exact one-action interventions
Formal X ACCEPT for every selected repair
```

The portfolio combines:

- direct visible-object acquisition;
- explicit task-phase transitions;
- closed-container state changes;
- loop/oscillation interruption;
- entity-index grounding repair;
- bounded search diversification.

The unselected 18 states remain explicitly deferred, not discarded. Their
rationales are preserved for Strong/Local Research Planner supervision.

## Strong API blind shadow

The package builds a compact 30-pair evidence input for the Strong Researcher.
It contains:

```text
policy scorecard
Analyzer evidence identities
experiment/resource history
round-level Researcher Memory
all 30 A2/A3 pairs
local/group mechanism summaries
Formal X evidence and disposition
A3 Analyzer Memory summaries
verification budget and authority boundary
```

It contains no Human selection, rationale, PRE bytes, or PRE hash. The Strong
Researcher must independently identify the bottleneck and select a portfolio or
abstain. Human and Strong outputs are compared only after both PRE records are
sealed.

## Training-data policy

At PRE, freeze eligibility—not the exact mixture:

```text
Benefit  → positive SFT / preference chosen eligible
Harm     → never positive SFT; rejected preference and counterexample eligible
Neutral  → analysis-only by default
Uncertain→ excluded from primary training
InfrastructureInvalid → no scientific label
```

The exact mixture is frozen only after the F0/F1 label census and eligibility
audit, before any trained-policy SELECT outcome is visible.

## Current exclusion

Success-trajectory optimization remains inactive. The first Human reference
round changes only failure-repair verification.
