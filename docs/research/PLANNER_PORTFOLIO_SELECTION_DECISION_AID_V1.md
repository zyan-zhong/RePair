# Planner Portfolio Selection Decision Aid V1

This module is a reusable **mechanical decision aid**, not the Research Planner's scientific authority.

It converts the canonical 30 A2/A3 state pairs into comparable structural features:

- evidence count;
- contradiction and residual evidence;
- X/cross-check dispositions;
- exact-action versus short-option intervention cost;
- task-family and group coverage;
- exact SHA overlap with the governed Researcher Memory.

It produces a transparent 12-state recommendation under the already frozen verification budget.
It never reads current-round F0/F1 outcomes or strong-model benchmark per-task results.

The Human reference must review the recommendation, record expected value, Harm risk,
historical NO-GO relevance, and a rationale for every accepted/overridden choice.
These PRE predictions are later compared against the independent verifier outcomes in POST.

Success-trajectory optimization remains dormant for this round.
