# Review materials and anonymity

This is an account-owned public development repository. Its URL and Git metadata
identify its owner; it is **not an anonymous review URL**, even though the paper
files use anonymous authors. Do not paste this repository URL into an anonymous
submission as if it concealed identity.

The [ICLR 2027 author guidelines](https://iclr.cc/Conferences/2027/AuthorGuidelines)
require anonymous submitted materials and allow an anonymized code ZIP or an
anonymous code repository. The previously prepared v4.3 numerical supplement is
an anonymous recount artifact. It contains task-paired summaries and the recount
program, not the complete training runtime. The paper describes that scope.

The `paper/` source and numerical evidence are the corresponding anonymous
manuscript materials. They can be read independently of the account-owned release.
Historical runtime files preserve original deployment locations and should not be
treated as an anonymous code artifact without a separate export and inspection.
Renaming the GitHub repository does not conceal its account or history.

For a separate anonymous code export, remove account links, local usernames,
private operational history, identifying Git metadata and embedded archives;
document any changed deployment references, rerun source checks/tests, and host
without visitor tracking. Do not describe such an export as byte-identical to
the original production bundle. No anonymous full-runtime link is claimed here.

Publication of this repository does not upload or revise an OpenReview submission.
Observe the conference's deadlines and allowed revision channels separately.
