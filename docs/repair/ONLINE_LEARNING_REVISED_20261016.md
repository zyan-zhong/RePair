已从登记authority→原生summary核实B_POLICY_REPLAY为55/355：seed17、Memory OFF、Harness OFF、benchmark feedback=false；原比较模型52/355。完整总账明确登记的candidate success字段最高也是55。最终比较仍要冻结参数/runtime、任务清单和完整协议身份，不能仅凭同为355或同seed就认定可比。若有效同协议最好值确定为55，严格超过就是至少56；持平或仅过程进步不满足新增RL准入条件。

55分候选、52分登记比较模型、当前研究候选和生产父模型分别记录。55分结果的native recommendation虽为PROMOTED，production promotion performed=false；不能据此授予生产authority，不能把跨分支差异自动称为连续遗忘。现有222430继续，它是SFT局部监督重心对照，尚无训练后收益结论。

## 为什么想到这样设计

| 真实现象／证据 | 建议与预期机制 | 替代解释、风险及如何证伪 |
|---|---|---|
| 完整教师SFT已覆盖417条研究样本、609,048个位置，开发调用仍2/10，固定反馈修订2/4→1/4 | 检查当前错误反馈和训练／推理一致性，不再无差别重放同样报告 | 也可能是事实呈现、内容偏差或容量问题；固定模型／事实后比较实际错误反馈，不能先认定换RL必好 |
| Native接受的报告仍能把一次环境动作与三次未执行非法命令说成“大量重复执行” | 事实、错误位置、修复依据分别核验；格式不能代理内容 | 事实字段正确仍不证明高层解释正确；改变一个事实，检查诊断／方案是否对应改变 |
| 局部修复、终局Benefit和双OFF收益不一一对应 | 分开评价过程、修复因果效用和能力；给每项反馈绑定证据 | “看起来有道理”的过程分会鼓励空话；用真实同状态实验检验对应预测，不凭文字长短评分 |
| 公平实验也会得到Neutral/Harm或证伪假设 | 公平设计、忠实解释可以是好研究行为；最后是否有用提供延迟反馈 | 不能每做一次实验就奖励；检查竞争预测是否真被区分，重复无新信息不靠调用数获奖 |
| 共享模型的多个角色会互相影响；三视图loss不能证明角色能力 | 按角色、决策记账，分阶段更新，再独立验收 | loss下降／奖励JSON不等于训练有效；需要有效token、非零LR、参数变化及后验能力证据 |

这些是待检验解释，不是已排除所有替代原因的结论。222430只检验其中局部监督重心，不同时证明整套设计有效。

## 离散评分的不足与论文依据

离散本身没有错：是否执行、引用是否真实可以是0/1；错误次数和目标条件比例可以是计数或连续量。第一稿的问题是**过早把整个研究产物压成一个总分**，丢掉“事实正确但假设弱”“实验公平但被证伪”等差别。改成主观0.73分同样不科学。

| 原始来源 | 实际机制 | 借鉴与差异 |
|---|---|---|
| [SEAL §3](https://arxiv.org/html/2506.10943v2) | 依据自编辑带来的实际更新后表现给二元奖励；作者报告PPO/GRPO不稳，采用筛选后SFT | 保留真实后验效果检验，但它没有提供RePair逐角色过程信用分配，不能覆盖所有前序研究判断 |
| [RISE §3–4](https://arxiv.org/html/2407.18219v2) | 顺序尝试—反馈—修订，目标累计各次正确性，实验使用奖励加权监督学习 | 学习当前学生的真实修订；不是只给最后答案一次分，也不表示本项目已实现RL |
| [SCoRe §5](https://arxiv.org/html/2409.12917v2) | 分别考虑两次正确性及其变化，区分错改对／对改错 | 支持纠错信用分配，但数学题答案真值不能代替研究机制真值 |
| [DeepSeekMath §4.1.3](https://arxiv.org/html/2402.03300) | 讨论步骤边界的过程奖励及由后续过程奖励构造优势 | GRPO不必给全文token贴同一终局分；其过程评分模型不能未经验证直接搬来 |

另外借鉴[GKD](https://arxiv.org/html/2306.13649v3)关注学生生成分布（原法有教师token概率，本项目没有完整外部logits）；参考[AgentGym-RL作者项目页](https://agentgym-rl.github.io/)的分阶段交互和[RAGEN-2](https://arxiv.org/html/2604.06268)的输入无关模板／奖励信号问题。只借机制，不声称复现原算法或继承性能；非零奖励方差也可能来自评分噪声。

## 先保存过程反馈向量，再决定如何优化

角色r的第d个结构化决策先保存z[r,d]：**各项原始指标、证据ref、有效性和不确定性**，不立即合成单一总分。

| 部分 | 正向反馈依据 | 负向反馈与限制 |
|---|---|---|
| Policy | 终局成功、登记目标条件的可靠净改善、相同机会／预算下更少非法或无效调用 | 终局退化、进度丢失、可确认非法动作；提前错误退出不能刷“零错误” |
| L | 事实引用与实际执行对应、错误定位、针对性修复、反馈后纠正真实错误 | 捏造执行、错认状态、无新依据重复建议已完成动作；修JSON不等于诊断改善 |
| G | 跨案例机制有支持、差异解释和适用边界 | 无依据推广、输入无关模板 |
| C／X | 能力判断有支持／反例，核查矛盾，保留竞争解释和不确定性 | 把上游假设说成事实、忽视反证；P继续用既有确定性汇总，不虚构研究奖励 |
| PRE | 可证伪假设、可区分预测、公平对照、可执行干预，预算／endpoint预冻 | 无依据方案、混改模型与状态、事后选指标；候选多／调用多不直接奖励 |
| POST | 忠实解释固定结果，正确TRAIN／NO_TRAIN／补证和U／PU处理 | N/P+改名Benefit、无资格TRAIN、掩盖负面结果；诚实承认实验失败可以是好研究 |
| Memory | 适用／排除条件、反例、出处，下一次正确使用与拒绝不适用经验 | 机械抄入、套用过期经验；写入数不奖励，永远拒绝也不算好 |

这些是拟验收维度，**不是现有全部都有可靠评分器**。能机械验证、需真实实验和仍未评分的项分开；未知机制质量不自动记0，也不凭教师自信给正分。

每项记录角色／阶段／决策ID、模型和输入SHA、输出span、事实／实验receipt、正负依据、原始量、有效mask、延迟反馈来源、是否进入目标及原因。当前已有SFT视图loss及原生输出，**逐决策RL奖励与反传尚未实现、未验收**。

## 中间过程怎样受到最终效果影响

可讨论形式是r[r,d]=f[r](本地证据、有效性约束)+η[r]u[r,d]。f评价该决策当时有无依据、是否公平／可执行／可证伪；u使用确实关联的后续实验、路由和memory结果。**η与聚合规则没有冻结，不实施。** 不把所有维度随意相加；Harm veto、eligibility和科学有效性保持独立。

例如：Analyzer正确发现非法命令，PRE公平验证修复，F1因后续另一错误仍失败，不能把前面一概罚掉；终局仍如实记Neutral-failure。若结果反驳原机制，应降低机制支持，不罚POST诚实更新认识。偶然成功也不能洗掉事实编造或不公平对照。

若未来用过程优势，作用位置应对应结构化决策及有可识别关系的前序决策，不能整篇无差别贴终局分。实际受约束采样的logprob、学生生成mask和teacher强制token隔离未核验前，不运行策略梯度。一次OFF/OFF变化由多个角色与训练共同造成，没有对照就不能归因给某段Analyzer文字；延迟结果首先更新置信与研究优先级，因果奖惩需要固定其他条件的小对照。

Policy进度只用已登记端点goal-condition vector，不冒称已有任意里程碑。前进又退回要抵消，反复拿起／丢下不重复计奖，混合增退PU保留未知。少犯错要同时考虑任务机会、完成度和预算；observation不变只是代理。终局B/H/N/U、过程P、效率和训练后能力分开；N-failure/P+不升级Benefit，T4 Benefit-only不混入progress-neutral。新的进度／错误辅助目标须另行批准，不能用细碎进步抵消终局Harm或独立能力下降。

潜势塑形的整段和为−Φ(s0)+γ^TΦ(sT)；真实有限时域终止Φ(sT)=0时同初态该项为常量，不能声称必然解决全失败GRPO同分。若保留终点进度区分失败，就是新增目标，不能套用原策略不变保证。[Ng等原论文](https://people.eecs.berkeley.edu/~russell/papers/icml99-shaping.pdf)。环境终止、预算终止、故障、非终端截断分开，不把未知／故障自动当负奖励。

## 损失、预算与下一步

现有ACTION／RESEARCH／STRATEGY=.4/.2/.4是SFT三视图权重，不是三个角色奖励权重；不自动改动。同一个本地共享LoRA分阶段更新，不表示其他角色参数被冻结；外部教师不更新。不加动态权重网络、多个critic或梯度手术。

验收分别证明：①评分有实际证据；②对应角色mask、有效token、非零LR、loss／优势与参数变化；③新来源的诊断、机制、PRE、POST、memory能力；④真实整链和双OFF。不能用总reward／loss遮盖某角色退化，也不能把奖励写盘当作训练到。研究角色可以学习正确处理Neutral/Harm，但错误修复不成为Policy正例。

**当前不增加RL调用，保留222430原定SFT与后验预算。** 在SFT严格超过最佳、且新设计批准后，先考虑2个来源×首答与一次修订=最多4次本地生成的评分审计，不更新参数；同模型／输入／协议首答可复用。只有反馈确能区分行为，再讨论单一GRPO组4条两次尝试=8次生成，加2个独立来源两次审计=4次，单分支最多12次；不同时开三分支。4／12都是待讨论预算，不是新运行授权，不能据此宣称统计泛化。

全同分／全失败不硬训，不用噪声或篇幅奖励造方差。来源从注册索引冻结；TRAIN_UPDATE、反复开发、新审计分开。TRAIN_SELECT仍355×单配对seed17，不参与RL奖励；最终134 unseen／140 seen隔离。额外API预算为0；Slurm限时参考实际耗时，真实更新须有非零LR与参数变化，不能让warmup冒充完成。

下一步先完成现有SFT实际验收，再按“证据→建议→预期机制→替代解释→小实验”补足评分依据，形成可审阅函数／系数／mask／预算。**尚未批准新的奖励、loss、eligibility、晋升或强模型接管。**
