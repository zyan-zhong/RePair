## 1. 要回答的问题与已经得到的证据

当前要区分的是：学生缺少针对自己错误的学习，还是现有输入／监督／评分仍不能区分正确研究与流畅模仿。不能再把研究 loss 下降解释成能力完成。

已登记的完整教师 SFT（作业 220221）覆盖了 417 条 RESEARCH 样本的 609,048 个监督位置。其训练首答原生接受 7/8→7/8，四个固定反馈修订 2/4→1/4，反复使用的来源隔离开发调用 2/10→2/10（五个任务，不是十个独立任务）。保留比较模型与该研究候选的控制结果为 0/10→2/10 原生接受；可比案例部分事实差异减少，但内容仍有错误。不能据此说完全没学到，也不能说学会了。

最近候选的独立双 OFF 选择评估为 51/355，登记比较基线为 52/355；新增成功 18、退化 19。目标条件比例有所上升，但不能覆盖成功数的下降，也没有生产晋升。这是已登记谱系的累计比较，不代表任意两条分支之间的连续遗忘。

作业 222430 是已提交的 **SFT 局部监督重点对照**：完整正学习率教师覆盖之后，只改变重复 Local 样本中 call_window / facts_at_trigger 的监督 mask。完整教师文本、输入、非 Local 与策略样本保留。它尚未提供训练后结果；不能作为本设计的有效性证据。其前一失败 222360 是新增辅助目标解析器错误引用历史 shared target，发生于优化前；修复改用当前 conditional target 与已有无损视图证明，没有重写原训练数据。

## 3. 数据与证据：评分必须先于优化可信

只沿 **status / manifest → 注册 typed index → exact asset + SHA** 取数据。下面是拟新增的记录字段，不声称现有所有 receipt 已具备它们；实施前逐项映射原字段，缺项明确不评分。

| 字段组 | 具体内容与来源 |
|---|---|
| 身份 | model parameter SHA、runtime SHA、初始化链、输入／schema／decoder SHA、source task / episode / state identity |
| 事实 | 原有 public transitions 的 model-call index、实际执行标记、literal action、admissible menu、observation、budget；非法命令与已执行环境动作分开 |
| 学生尝试 | role / stage、原始首答及 SHA、Native 校验结果、事实校验差异、反馈 receipt、修订原文及 SHA |
| 教师 | 当前已准入 teacher target ref、历史来源 ref、必要上下文；conditional target 优先于旧 shared provenance；不能用教师文字覆盖环境事实 |
| 研究检验 | 证据引用、错误位置、竞争解释、预测、PRE 的固定对照／预算／endpoint、执行绑定、真实 paired results、POST 路由 |
| 记忆 | scope、触发／排除条件、支持／反证、实验结果、出处；下一次调用的检索／使用／拒绝记录 |
| RL 专属 | behavior model / sampling settings、学生生成 token mask、实际采样分布 logprob、组 identity、角色评分及判据、有效／未评分原因 |

先核查现有 constrained decoder 是否能记录**实际受约束采样分布**的 logprob 与合法支持集。若只有原始模型 logits，不能把它们直接当作该采样的行为概率。强制模板／教师注入 token 不计入学生策略梯度。这个接口未验证前，小规模 GRPO 只能停在设计与采样审计，不能用近似概率冒充已实现。

机械检查可以判定“只有一次环境动作、三次非法命令未执行”，却不能独立证明某个高层机制解释正确。未核验的机制／预测记 **UNRATED**，不自动记 0 或 1；Native 合法只是一项前置检查。

## 4. 按角色评分，而非按 Benefit 数量评分

拟采用离散 q_r∈{-1,0,+1,⊥}，不把几十个指标随意相加：

- **+1**：该案例预先列明的所有适用科学要求都有可核验证据。
- **0**：可判定但仅部分成立／未解决，且没有下述严重错误。
- **−1**：可核验的严重事实矛盾、捏造执行／出处，或无依据的 TRAIN 路由。
- **⊥**：真值／证据不足、评分冲突未解、环境／提供商故障；不参与梯度和组标准化。它不等于模型答错。

每个角色分开判，先冻结要求，不用一个总分掩盖退化：

| 角色 | +1 所需证据 | 不能作为 +1 的替代物 |
|---|---|---|
| L | 正确区分调用与执行、引用实际事实、定位错误、解释为何修复针对该错误 | 合法动作、格式通过、重复教师名词 |
| G / C / X | 跨来源机制有对应支持／反例；能力判断有边界；预测能被实验反驳 | 各案例套用同一个流畅模板；假设数量多 |
| P | 既有确定性汇总正确 | 不作为需要 RL 学习的强模型判断 |
| PRE | 候选有依据、竞争预测不同、相同冻结策略／配对状态／预算、公平对照、可执行且 endpoint 预冻 | 多选几个候选；事后选择指标；只证明指令送达 |
| POST | 忠实使用固定 B/H/N/U、处理 PU／不确定性，按既有 eligibility 路由，记录代价与下一问题 | Benefit 多；为了训练把 Neutral 改名 Benefit |
| Memory 使用 | 在适用的新情境引用正确经验，在反例／不适用时拒绝套用，有来源和结果 | 写入条数、JSON 正确、永远拒绝使用 |

准确证伪的 Neutral/Harm 实验也可以使 PRE/POST 得 +1。若证据充足却无理由弃权，不能靠弃权拿 +1；只有预登记的证据不足案例中，恰当弃权才是正确答案。上述科学 rubric 需要独立复核；缺可靠评分的角色不提前启动 RL。

**真实问题与拟议评分例子：**

1. 轨迹一次环境动作、三次非法命令未执行；学生称“大量重复执行”，并再次建议已完成导航：即使 Native 接受，L=-1。
2. 同一证据中，学生定位非法命令、引用对应 menu／call index，提出合法且尚未执行的替代并说明前提：仅在具体事实与原生接口核验后 L 可为 +1。
3. 修复真实结果 N-failure/P+；POST 保留 Neutral、拒绝加入 T4，记录真实进度及适用边界：POST 可为 +1，Policy Benefit eligibility 仍为 false。
4. 有害修复 H，POST 宣称成功并 TRAIN：POST=-1，训练路由硬性拒绝；不能靠效率或进度分抵消。
5. 相同 memory 在相似案例适用，在另一个前提不成立的案例不适用：必须分别正确使用／拒绝，不能只验一个记忆读取成功。

例 1 有历史证据；其余为待冻结判据的说明例，**不是新跑出的实验结果**。

## 5. 三个分支与具体损失建议

三分支共享同一已核验起点，使用相同输入呈现、可见事实、Native 校验器、输出预算与来源隔离。首个对照只检验 **L 的事实诊断和反馈纠错**，不声称验收完整研究能力。

**A：当前错误条件化 SFT。** 首答 y₁ 来自当前学生；机械反馈 f₁ 只描述它实际犯的错误。使用已核验完整教师修订 y*：

L_A = − mean_token log πθ(y* | x,y₁,f₁)。

本次零 API 方案中的 y* 是已有教师报告，不是重新向教师提交当前错误获得的新回答。必须验证其与当前事实／反馈相容，并披露这一差异；不能称为完整实现 GKD 或 RISE。输入超限时不截断掉关键事实或偷偷降低输出上限。

**B：采样、验收、SFT。** 对同一 x 采样四条两次尝试；只把有可靠 q=+1 的学生输出作为该研究角色的监督目标，完整保留证据上下文。没有合格样本则记录无可用正例并跳过该次更新，不拿格式通过补位。这是 rejection-sampled SFT 风格，不等于已复现 SEAL。

**C：小规模 GRPO。** 同一输入、同一初始行为模型、同一反馈协议下的四条两次尝试构成一组。拟定两次尝试回报：

Rᵢ = qᵢ₁ + qᵢ₂ + 0.5(qᵢ₂−qᵢ₁) = 0.5qᵢ₁ + 1.5qᵢ₂。

这三个系数都是**新增建议，待批准**。典型值：1→1 为2，0→1 为1.5，1→0 为0.5，0→0 为0，−1→−1 为−2。首答仍有正权重，不以故意先答错为最优；但这不是防投机或能力泛化保证。必须单报首答、错改对、对改错、保持正确、仍错和未评分。

只对可靠评分成员计算 Aᵢ=(Rᵢ−组均值)/(组标准差+10⁻⁶)。若不足两个可靠成员或全部同分，**跳过整个该组研究更新**，不注入噪声、长度奖或纯 KL 更新制造训练进度。所有模型都失败同分是信号不足，不是工程失败。

令 ρᵢₜ=πθ(yᵢₜ|hᵢₜ)/πold(yᵢₜ|hᵢₜ)，mᵢₜ 仅覆盖实际学生生成 token：

J = meanᵢ [ sumₜ mᵢₜ { min(ρᵢₜ Aᵢ, clip(ρᵢₜ,0.8,1.2) Aᵢ) − 0.02 KL(πθ||πref) } / sumₜ mᵢₜ ]。

clip=.2、KL=.02、数值稳定项10⁻⁶为本设计拟定值，非历史参数；KL 在实际受约束支持集上计算／估计。对两轮共同用轨迹优势是粗粒度信用分配，不能据此解释逐 token 的科学贡献；若信号只来自格式，试验不通过。

角色内 q／R 聚合与外层损失不同。提议仍用：

L_total = .4 L_ACTION,replay + .2 L_RESEARCH,branch + .4 L_STRATEGY,replay。

A/B 的研究项是 token 均值 CE，C 是 −J；三项数值尺度不同，沿用系数**不保证梯度等量**。记录各项 loss、有效 token、update 次数与实际学习率；先做一个更新审计，不加入动态权重网络／多个 critic／梯度手术。该统一损失对照仍需本次明确批准，不能援引旧 .4/.2/.4 自动授权新 RL。

## 6. Policy 的后续对照：本次不启动

Policy 与研究角色分阶段，不能把研究诊断奖励直接贴给所有环境动作。未来首先比较终局成功奖励和终局加端点进度辅助目标，效率项后续单变量验证。

终局主目标 r_T=S∈{0,1}。如另行批准辅助目标，可设 g 为同一任务已登记 goal-condition vector 的端点净变化均值，g∈[-1,1]，仅对可靠、可比、非混合 PU 情况可用，提议 r_TP=S+0.1g。混合增退或证据不完整时 g 缺失，不能当作0或排到已知 P−之上；这类 rollout 只进入独立终局目标组，不与有 g 的组混算优势。

| 真实冻结策略 F0/F1 结论 | 保留的研究身份 | 后续 Policy 辅助解释 |
|---|---|---|
| B | 终局 Benefit | 仍需既有 eligibility 与真实执行证据 |
| N-failure/P+ | 失败未变但机械目标条件改善 | 只可能进入另行批准的辅助训练池，绝不进入当前 T4 |
| N-failure/P0 | 无可靠进度差异 | 终局失败；不伪造积极信号 |
| N-failure/P− | 更差的目标条件 | 辅助目标为负；不能用省步数抵消 |
| N-success | 都成功 | 终局主目标优先；后续效率另测 |
| H | 终局 Harm | 既有 Harm veto；进度／效率不能解禁 |
| U / PU | 不确定 | 保留缺失／弃权，不改成确定零 |

上表 B/H/N/U 只用于**同一冻结策略的 repair 因果验证**；不同权重的 OFF/OFF 比较不自动称为 F0/F1 或 B/H。

S+.1g 的单次成功样本分值区间高于失败样本，但**不能保证期望成功率或一次策略更新不退化**，也不是严格词典序优化。独立成功数优先的验收与晋升规则不变。此奖励改变学习目标，不具备潜势塑形的策略不变保证。

潜势塑形 F=γΦ(s′)−Φ(s) 的整段折扣和为 −Φ(s₀)+γᵀΦ(s_T)。有限时域真实终止且 Φ(s_T)=0 时，同一初态整段回报的这部分为常量；不能据此声称解决整段 GRPO 全失败同分。若保留终点进度用于区分失败，就须承认新增目标，不再套用该保证。原理论还要求相应 MDP、折扣和有界／终端条件，不能无条件迁移。

环境正常终止、任务预算终止、基础设施中断、非终端截断分开记录。截断不是自动失败或零潜势；无已验证 bootstrap 不拼接假回报。只计算净端点进度，不给反复拿起／丢下重复奖金；目标条件丢失计入净值。公开 observation 不变仅为代理现象。

效率保留 steps、remaining budget、repeated actions、revisits、policy calls、tokens 等原始指标。初次对照的效率奖励系数为0；之后若试罚项，必须另行冻结其有效性与预算，防止提前错误退出刷效率。

## 7. 建议批准的首个预算与判定

本段是提议上限，**未提交作业**。先等待 222430 结果；若其修复事实表示问题，先接收结果，不重复同类 SFT。

| 阶段 | 固定上限 | 回答的问题 |
|---|---|---|
| 三分支微型对照 | 每分支2个 TRAIN_UPDATE 输入×4条两次尝试=16次本地生成，最多1次参数更新 | 当前错误反馈、采样筛选和相对奖励是否产生可用不同信号 |
| 新来源微型审计 | 每分支4个未用于更新且非旧反复开发来源×两次尝试=8次本地生成 | 是否仅记住训练案例；检验内容及纠错，不宣称泛化达标 |
| 总计 | 每分支最多24次，三分支最多72次；每次沿用12,288输出上限，总输出最坏884,736 tokens；新增外部API=0 | 上限不是预期用量；缓存和实际 tokens 单报 |

同一批初始 on-policy 采样可在分支中复用，只有行为模型／输入／采样协议 SHA 完全相同才复用，不能把 teacher-forced 输出称 on-policy。分支更新后产生的回答不能跨分支冒充同一行为模型。

训练基准是同起点、同采样与上限；A/B/C 的实际可用目标长度／合格样本数可能不同，不能宣称严格相等训练 token。复用相同 Policy replay、优化器与已有学习率；记录实际 supervised tokens、角色 loss、组方差、KL、梯度 finite 与参数变化。只有支持集／logprob、可靠奖励和更新审计均通过才允许 C 的那一次更新；否则报告 C 尚不可执行，不偷偷替换算法。

输入 identity 与 source isolation 从注册索引冻结，四个新审计来源是否足量尚需 exact materialization 证明；不凭空制造“新 holdout”。已反复查看的开发集只作诊断。评分只允许已核验字段；不能为凑预算新调用教师或扫描目录。

Slurm 限时按最近同类型10调用约21–27分钟、24调用约50–65分钟的粗估，加模型加载与一次更新余量，**提议每分支≤2小时**；部署前用准确历史耗时和token量核验。若预算容纳不了完整样本，先减少预登记样本数并报告，不中途截断科学产物或扩大限时。当前222430的3.5小时是305步既有SFT，不套用这个一更新预算。

初筛不是全能验收。最少要求：无严重事实编造／错误 TRAIN 路由；新来源首答及净纠错不下降；没有用同分组制造梯度；模型输出随证据改变有对应变化。4例是可行性检查，无法给出可靠统计泛化结论。

只有诊断通过的候选才向同一个原生链路推进：G/C/X/P → PRE → 小规模真实 F0/F1 → POST → memory 写回与下一调用适用／不适用对照 → 355任务单seed17双OFF。PRE 的因果 seeds 从其自身 authority 取，不拿 TRAIN_SELECT 的单seed覆盖因果重复。最终 benchmark 不进入任何奖励。不得用新总reward覆盖该链任何一项失败。

|---|---|---|---|
| [GKD](https://arxiv.org/html/2306.13649v3) | 在学生实际生成分布上学习，针对当前错误而非静态历史错误 | 原法使用教师token概率；本项目无外部完整logits，A使用文本监督 | 相同预算下当前错误反馈优于历史错误反馈，否则此解释不足 |

| [SEAL](https://arxiv.org/html/2506.10943v2) | 用真实更新后效果检验学习方案；支持比较采样后SFT | 作者报告其PPO/GRPO不稳后采用ReST-EM；本项目不启动嵌套自编辑训练 | 筛选报告不能替代更新后新来源收益；若无合格采样则B无学习信号 |

## 9. 审阅决定与实施边界

建议首先批准 **第3–5、7节的L层三分支微型对照**，包括评分{-1,0,+1,未评分}、两次尝试回报(.5,1.5)、GRPO clip .2／KL .02、保持外层 .4/.2/.4、每分支最多24次本地生成／一次更新／2小时、零新增外部API。支持集logprob或可靠评分未具备时C不更新，先报告该缺口。

第6节 Policy 进度奖励、效率罚项、其他研究角色的奖励实施、改变eligibility／晋升、接管外部教师、整轮在线RL **均不在这个首试批准范围内**。另行得到具体确认才能启用。

本设计可以归档；归档不是训练批准。现有SFT修复不再重复询问。当前正确结论仍是：部分研究内容已训练到，研究整链与策略保持未完成；保持外部强模型生产接线。
