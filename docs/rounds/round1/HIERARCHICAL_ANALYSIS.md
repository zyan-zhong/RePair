## Purpose

This document is the canonical Round-1 map of the multi-level semantic post-hoc analysis performed after the first pi0-to-pi1 Harness-OFF evaluation ended in `NO-GO`.

It records the actual evidence universe, request structure, semantic analyzers, deterministic validation boundaries, outputs and scientific disposition of Levels 1-6.

It is a navigation and provenance document. It does not rerun or reinterpret the original analyses.

## Shared Evidence and Missingness Rules

The hierarchy begins from 85 matched groups spanning 17 task identities.

For the external Level-1 semantic analyzer:

- 73 groups produced validated semantic outputs;
- 6 groups ended with provider-response incomplete rejection;
- 6 groups ended with ambiguous post-send/no-retry disposition;
- therefore 12 groups are semantic-unavailable;
- among the 73 validated groups, 50 form the complete-core population and 23 are partial-validated evidence.

A validated group with zero claims for a component or mechanism is an observed zero. It is not missing evidence.

Missing semantic output is preserved explicitly and is never removed from the registered population denominator by silently conditioning on claim-positive groups.

The local analyzer was a shadow condition only: 57 of 85 outputs passed its semantic validation, and the registered `local_shadow_decision_authority` is false.
