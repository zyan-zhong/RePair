# V1.23.2W — Dynamic Strong Planner PRE V2 autonomous infrastructure reconciliation

This package is a narrow continuation of V1.23.2V. It does not change Dynamic PRE V2 science, pair selection, Researcher Memory, provider model, prompt/schema, candidate universe, or F0/F1 protocol.

It fixes one orchestration seam: V1.23.2V collapsed every non-ACCEPTED PRE terminal into `FAIL_CLOSED_NO_AUTOMATIC_RESEND`. V1.23.2W reuses the historical exact infrastructure-recovery classifier and only permits a new immutable remediation logical call for machine-proven SAFE_PRE_SEND or SAFE_PROVIDER_REJECTION.

Ambiguous/maybe-sent, auth/config, runtime-adapter, method/output/semantic failures remain no-retry. The original logical-call directory is immutable; same logical-call resend count remains zero.

The invocation-start flag `--authorize-bounded-infrastructure-recovery` authorizes the frozen infrastructure policy, not a scientific decision. No per-incident Human disposition is required.
